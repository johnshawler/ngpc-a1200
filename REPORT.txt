PORT REPORT
Game:                  Neo Turf Masters (SNK 1999, Neo Geo Pocket Color, World release, 2 MB cartridge, 60 Hz).
                       This is the state after bringing the Neo Geo Pocket Color tools up on it, not a finished port.
Class and route:       Binary TLCS-900/H code. The Step 1 table has no row for this CPU; the route is the one of its row
                       "Assembly or disassembly for a Z80, 6502 or 6809 machine": translated once on the host
                       (tools/recomp900.py) to C, entry points found by tracing the game on a reference machine
                       (tools/ngpref). K2GE, BIOS calls, interrupts and the Z80 sound processor are plain-C state
                       (src/ngpc/ngp.c). The user supplied the cartridge and BIOS images and asked for the tools.
Display:               planes=8 scroll=0 fetch=3 buffers=2 sprites used=0 colours=256 (the K2GE's 256 palette entries
                       are the pens). First display only: every pixel computed from the K2GE's memory, converted with
                       the kit's C2P routine, 160 x 152 shown as 320 x 152. No planar display yet.
Busiest moment:        ball flight and hole views: both scroll planes, sprites, music. Not a Step 2 sum: measured on the
                       reference machine the main CPU runs 1,700-3,900 instructions a frame there (5,200 at the 90th
                       percentile, 13,100 at scene changes) and the sound program 1,500-4,200 (up to 6,200).
Cut from the original: sound (the sound program runs, nothing plays it); saved games (flash writes are accepted and
                       forgotten); the serial link; the date (fixed). Raster effects: not modelled, and not seen used
                       by this game in the bench (it takes the vertical blank interrupt only).
Stock A1200 bench:     no bench.txt. The program ends before the takeover with "cannot load rom.bin: file missing, or
                       not enough memory for the cartridge": the cartridge holds 1,544 KB of data.
                       (FS-UAE 3.1.66, tools/bench.sh dist ntm 300, AROS ROM)
With 4 MB fast RAM:    tools/port.sh fast (3,600 ticks): FAIL, "NO bench.txt (crashed, hung, or did not finish in 204 s)":
                       the port is too slow to play 3,600 ticks in the referee's time.

Host checksum:         fa876f99 after 300 ticks, 544160df after 900 ticks: equal to the Amiga's both times.
                       dfdb0755 after 3,600 ticks on the host; the Amiga was not run that far (not measured).
                       On the host the translation equals the interpreter after every one of 3,600 ticks
                       (tools/verify_ngpc.sh 3600: work RAM, shared RAM and K2GE memory compared each tick).
Frame rate claim:      0.9 pictures a second over the first 300 ticks and 0.3 over the first 900, with 4 MB fast RAM.
                       Game time is NOT kept: the logic alone takes 205,074 colour clocks a tick (300 ticks) and
                       764,273 (900 ticks) against a frame of 71,051. 50 Hz is not held and the stock machine does
                       not start. Where the time goes, solved from those two benches: about 249 colour clocks for
                       every instruction of the sound program (it runs through a Z80 interpreter, which the brief
                       forbids; it is there so that the logic is complete and provable) and about 53 for every
                       translated instruction of the main CPU (C with the registers in memory). The sound program
                       is 86% of the logic time over the 900 ticks. The first display takes 25 to 30 frames a picture.
                       Cheapest upgrade likely to reach 50 Hz: not measured, and not known before the sound program
                       is translated and the main CPU has a 68k back end.
Not done, not tested:  a display that can hold 50 Hz; sound; a 68k back end; translation of the sound program; real
                       A1200 hardware; a Commodore Kickstart ROM; NTSC; a real Neo Geo Pocket (the reference machine was
                       compared with Mednafen 1.29: two pictures of the intro, 0 of 24,320 pixels differ; with nothing
                       else); play by a person (controls are wired, untested); scenes beyond the bench (title, menus,
                       course intro, first hole): their code is not traced, so the port stops there with reason 2;
                       CI (the images cannot be committed to this public repository).
How to run:            put the cartridge image at original/ntm.ngc and, if you have it, the BIOS image at
                       original/bios.ngp; PORT_CONF=port.ngpc.conf tools/make_assets_ngpc.sh; then
                       PORT_CONF=port.ngpc.conf tools/port.sh fast (or tools/long_bench.sh dist ntm 300 400 -
                       --fast_memory=4096 for a run that finishes). Copy dist/ntm, dist/rom.bin and dist/font.bin to
                       an Amiga with fast RAM and run "ntm" from a Shell ("ntm bench 300" for the proof run).
                       Joystick in port 2: stick = pad, fire = A, second fire = B. Keys: cursor keys = pad, X = A,
                       Z = B, Space or Return = Option, Esc = quit.
