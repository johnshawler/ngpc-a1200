PORT REPORT
Game:                  Neo Turf Masters (SNK 1999, Neo Geo Pocket Color, World release, 2 MB cartridge, 60 Hz).
                       Work in progress: correct, plays through the bench on the emulated A1200 with fast RAM, with
                       its music and sound effects, not yet at full speed.
Class and route:       Binary TLCS-900/H code. The Step 1 table has no row for this CPU; the route is the one of its row
                       "Assembly or disassembly for a Z80, 6502 or 6809 machine": translated once on the host
                       (tools/recomp900.py) to C, entry points found by tracing the game on a reference machine
                       (tools/ngpref), and from there to 68k assembly (tools/back900.py: TLCS registers in 68k registers;
                       BACKEND=c in port.conf builds the C instead). K2GE, BIOS calls and interrupts are plain-C state
                       (src/ngpc/ngp.c). The Z80 sound
                       program is not run at all on the Amiga: what the game sees of it (an answer to each command, a
                       tick counter) is modelled, and tools/check_sound_ngpc.sh proves the model against the real
                       program, tick by tick. The display class is per-pixel (CLASS=perpixel), for the reasons below.
Display:               planes=8 scroll=0 fetch=3 buffers=2 sprites used=0 colours=256 (the K2GE's 256 palette entries
                       are the pens). The 160 x 152 picture at its own size in the middle of a black 320 x 256 screen
                       (the user's choice). Drawn into a byte buffer by k2ge_frame_cached (scroll planes kept drawn,
                       redrawn only where the game changed cells or characters) and converted row by row with the
                       kit's c2p1x1_8_c5_gen. A picture is drawn only when the game changed the K2GE's memory, and
                       then only its lines whose inputs changed; only rows written since a screen buffer last got
                       them are converted into it.
Busiest moment:        play (ball flight and course views: both scroll planes, sprites, new picture every frame). Not
                       a Step 2 sum: the reference machine measures 1,700-3,900 main-CPU instructions a frame there
                       (5,200 at the 90th percentile, 13,100 at scene changes). On the Amiga, logic averages 22,751
                       colour clocks a tick over the bench, a picture 182,312 to draw and 70,968 to convert.
Cut from the original: the Z80 itself: its music and effects are recordings of the game's own sound program made on the
                       host per command (tools/sndrec_ngpc.c), mixed and played on Paula; stereo is folded to one
                       side per voice; commands the bench never sends play nothing; saved games (flash writes
                       are accepted and forgotten); the serial link; the date (fixed). Raster effects: not modelled, and
                       not seen used by this game in the bench (it takes the vertical blank interrupt only).
Stock A1200 bench:     no bench.txt: the program ends before the takeover ("cannot load rom.bin: file missing, or not
                       enough memory for the cartridge"). The cartridge holds 1,544 KB of data.
                       (FS-UAE 3.1.66, tools/bench.sh dist ntm 300, AROS ROM)
With 4 MB fast RAM:    tools/port.sh fast (3,600 ticks):
                       frames=1231 late=1922 worst_cck=1307802 avg_cck=137068 budget_cck=71051 worst_pct=1840 avg_pct=192 display_hz=50 shown_fps=19.5
                       ticks=3600 checksum=ac36a76c game_speed=95%
                       logic_cck=22751 max=451508 pics=285/472 draw_cck=182312 conv_cck=70968
                       PASS (per-pixel game: 19.5 pictures a second, game time at 95% of the clock: it falls behind where
                       a pass takes more than 8 frames). With sound playing. A pass whose ticks took over 2 frames
                       draws no new picture (at most 8 in a row); without that rule (and before block copies were
                       one call): 15.1 and 83%.
Host checksum:         ac36a76c after 3,600 ticks: equal. On the host the translation equals the interpreter after every
                       one of 3,600 ticks (tools/verify_ngpc.sh: RAM, K2GE, ports, registers), the sound model equals
                       the real sound program as the game sees it after every one of 3,600 ticks
                       (tools/check_sound_ngpc.sh), and the renderers equal the reference renderer after every tick
                       (host_test -k). The music and effects the Amiga plays: per voice, 93-98% of the 50 Hz frames
                       where it sounds hold the same note and volume as the real sound program within 3 frames and one
                       volume step, 80-92% exactly for the tones (tools/check_music_ngpc.sh, 3,600 ticks).
Frame rate claim:      With 4 MB fast RAM: logic at 60 ticks a second where a pass stays within 8 frames; over the whole
                       bench game time runs at 95% of the clock. Pictures: the kit's shown_fps (19.5) counts passes,
                       each of which shows the newest picture drawn so far; new pictures drawn: 285 in 3,153 vertical
                       blanks (63.1 s), 4.5 a second. The game changes its picture in 823 of the 3,600 ticks
                       (host_test prints it), 13.7 a second at its 60 Hz: the Amiga shows about a third of its picture
                       changes, every change of colours (fades) and all of its game time but 5%. 50 Hz is not held
                       and the stock machine does not start.
                       Where the time goes (1 kHz profiler, 900 ticks): drawing the picture, the conversion, and the
                       translated game code. Game time is lost in the passes over 8 frames: scene changes, where
                       single ticks run up to 17,000 main-CPU instructions and change 7,600 bytes of video memory
                       (up to 451,508 colour clocks, 6.4 frames, for one tick).
                       Cheapest upgrade likely to reach full game speed: not measured.
Not done, not tested:  sound beyond the commands the bench sends; DAC samples; a display that holds 50 Hz; real A1200 hardware; a Commodore Kickstart
                       ROM; NTSC; a real Neo Geo Pocket (the reference machine was compared with Mednafen 1.29: two
                       pictures of the intro, 0 of 24,320 pixels differ); play by a person (controls are wired,
                       untested); scenes beyond the bench (title, menus, course intro, first hole): their code is not
                       traced, so the port stops there with reason 2; the profiling build on runs longer than 900 ticks
                       (it did not finish 3,600); CI (the images cannot be committed to this public repository).
How to run:            put the cartridge image at original/ntm.ngc and, if you have it, the BIOS image at
                       original/bios.ngp; tools/make_assets_ngpc.sh; then tools/port.sh fast. Copy dist/ntm,
                       dist/rom.bin, dist/font.bin and dist/sound.bin to an Amiga with fast RAM and run "ntm" from a Shell ("ntm bench
                       3600" for the proof run). Joystick in port 2: stick = pad, fire = A, second fire = B. Keys: cursor
                       keys = pad, X = A, Z = B, Space or Return = Option, Esc = quit.
